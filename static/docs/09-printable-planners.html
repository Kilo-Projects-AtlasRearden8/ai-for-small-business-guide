Printable Planners

Print these pages and fill them in by hand. They work away from the screen, and none of them ask you to type real customer or financial data into a computer.

You can print any page from the static HTML site (static/planners/) using your browser's Print command. Each planner page has a print-friendly layout.

How to print

  1. Open the planner page you want in a browser (from static/planners/).
  2. Press Ctrl+P (or Cmd+P on Mac).
  3. Choose "Print to PDF" or your printer.
  4. Uncheck headers/footers if your browser offers it, for a cleaner page.
