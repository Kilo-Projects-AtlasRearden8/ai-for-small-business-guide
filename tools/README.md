# Open-source apps and templates

This folder holds the open-source apps and templates published by
**Asdale Dynamics, LLC**. They are beginner-friendly, local-first, and free to
use, modify, and share under the MIT License.

| Tool | What it does | How to run |
|------|--------------|------------|
| [prompt-tool](prompt-tool/) | Builds a ready-to-copy AI prompt from a few choices | Open `index.html` in a browser |
| [local-llm-cli](local-llm-cli/) | Chats with a model running locally via Ollama | `python3 ollama_chat.py "..."` |
| [mcp-server-template](mcp-server-template/) | Minimal stdio MCP server skeleton | `python3 mcp_server.py` |
| [agent-skill-template](agent-skill-template/) | Sample agent skill + manifest (invoice reminder) | `python3 draft_invoice_reminder.py ...` |

## Safety first

- No API keys, no secrets, no real customer or financial data anywhere in these tools.
- Use fake or example data when testing.
- Read every output before you send it to a customer or file it with the
  government. AI is a helper, not an accountant or a lawyer.
