# Prompt Builder

A standalone, client-side tool that helps you write better prompts for free AI
chats. Fill in your business type, task, tone, length, and audience, then copy
the finished prompt and paste it into your AI chat of choice.

## How to use

1. Open `tools/prompt-tool/index.html` in any web browser.
2. Choose your business type, the task you want help with, the tone, length,
   and audience.
3. Add any key details — using **fake names and amounts only**. Never paste real
   customer or financial data.
4. Click **Build prompt**, then **Copy to clipboard**.
5. Paste the prompt into a free AI chat (ChatGPT, Claude, Gemini, Copilot, or
   your local model). Read the result and add real details yourself before
   sending anything to a customer.

## What it is

This is a template builder, not an AI model. Nothing you type is sent to a
server — the prompt is assembled in your browser and stays on your computer.
