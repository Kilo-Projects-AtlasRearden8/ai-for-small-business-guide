# Agents and MCP

This chapter explains AI agents and the Model Context Protocol (MCP) in plain
English. You do not need to code anything here — just understand the ideas so
you can decide if they are useful for your LLC.

## What is an AI agent?

A regular AI chat answers one question at a time. An AI agent is a step
further: it can plan a small task and carry out several steps on its own, while
you supervise.

Example of a simple agent task:
- "Check my inbox for messages from customers, draft replies for the simple
  ones, and flag the rest for me."

Agents are still new. They can make mistakes, so you should review their work
before anything goes to a customer or the government.

## What is MCP?

MCP (Model Context Protocol) is a way for an AI to connect to tools and data
you already use — like files on your computer, a calendar, or a website — using
a common standard, instead of building a separate connection for every tool.

Think of MCP like a USB port for AI: one plug that works with many devices.

## Should a small business use this?

Maybe, eventually. For now:

- Start with regular AI chat (Chapters 1–8).
- If you find yourself doing the same multi-step task every week, look into
  simple automation (Chapter 13).
- Agents and MCP are worth watching, but they are not required to run a
  business with AI.

## Safety with agents and MCP

- Never connect an agent to your bank account, email password, or customer
  database.
- Never give an agent access to real customer data.
- If you experiment with MCP servers, only use ones you trust, and only with
  fake or public data.
