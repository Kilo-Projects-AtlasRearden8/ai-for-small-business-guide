# Free AI Coding and GitHub

You can write simple software with free AI help and publish it on GitHub for
free. You do not need to be a programmer.

## What AI can help you write

- Small scripts to rename files, merge PDFs, or resize images
- Simple websites
- Spreadsheet formulas (Excel/Google Sheets)
- Tiny automations for your business

## Step-by-step: your first AI-written script

1. Open a free AI chat.
2. Say what you want in plain English. Example:

   > "Write a Python script that renames all files in a folder by adding the
   > date to the front of each name. Explain how to run it, step by step."

3. Copy the code into a file on your computer (e.g. `rename.py`).
4. Read the code. Make sure you understand what it does before running it.
5. Try it on a folder with copies of files, not your only originals.
6. If something breaks, paste the error message back to the AI and ask for a
   fix.

Never paste real customer or financial data into code examples. Use fake file
names and fake data.

## GitHub: where to keep your code

GitHub (github.com) is a free place to store code and documents, track changes,
and share projects. It is also useful for storing the plain-text versions of
your manuals, planners, and templates.

### Create a free account

1. Go to github.com and sign up with an email address.
2. Verify your email.
3. Turn on two-factor authentication in settings.

### Create your first repository

A repository (repo) is like a folder for a project.

1. Click the "+" menu → "New repository."
2. Name it something like `small-business-ai-tools`.
3. Choose "Public" or "Private." Private means only you can see it.
4. Click "Create repository."
5. Upload files or paste code directly in the browser.

You do not need to learn Git commands to start. GitHub works in the browser.
