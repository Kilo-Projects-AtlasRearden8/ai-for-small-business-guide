# Glossary

Plain-English definitions for terms used in this manual.

**AI (artificial intelligence)** — Computer programs that read, write, and
respond like a person would, but can make mistakes.

**Prompt** — The message you type to an AI.

**LLM (large language model)** — The kind of AI behind most chatbots. It
predicts the next word based on patterns it learned.

**LLC (limited liability company)** — A business structure that helps keep
personal and business finances separate.

**SOP (standard operating procedure)** — A written, step-by-step recipe for a
recurring task.

**MCP (Model Context Protocol)** — A standard way for AI to connect to tools
and data.

**Local AI** — AI that runs on your own computer instead of a website.

**GitHub** — A free website for storing code and documents.

**Repository (repo)** — A folder of files stored on GitHub.

**KDP (Kindle Direct Publishing)** — Amazon's free self-publishing platform.

**Markdown** — A simple way to format text with symbols like `#` for headings.

**CSV** — A plain-text spreadsheet format (comma-separated values).
