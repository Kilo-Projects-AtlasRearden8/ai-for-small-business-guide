# Printable Planners

Print these pages and fill them in by hand. They work away from the screen,
and none of them ask you to type real customer or financial data into a
computer.

You can print any page from the static HTML site (static/planners/) using your
browser's Print command. Each planner page has a print-friendly layout.

## Planner 1: Low-Energy Day Planner (ADHD-friendly)

When energy is low, pick only three things. This planner keeps the day tiny and
doable.

```
LOW-ENERGY DAY
Date: _______________

Must do today (pick 1-3):
1. ______________________________________________
2. ______________________________________________
3. ______________________________________________

If I have extra energy:
- ______________________________________________
- ______________________________________________

Breaks I will take:
- ______________________________________________
- ______________________________________________

Done today: ☐☐☐
```

## Planner 3: Customer Email Worksheet

Draft customer emails on paper first. Only type real details into your email
program at the very end.

## How to print

1. Open the planner page you want in a browser (from static/planners/).
2. Press Ctrl+P (or Cmd+P on Mac).
3. Choose "Print to PDF" or your printer.
4. Uncheck headers/footers if your browser offers it, for a cleaner page.
